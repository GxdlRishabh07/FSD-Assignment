## 🚀 Features

- **Serial-Wise Display:** All 6 practical assignments are neatly presented in sequential order (#01 to #06) on the main hub.
- **Dedicated Assignment Pages:** Clicking on any assignment launches its practical on a dedicated page link with previous/next pagination and a return link to the hub.
- **Pure & Clean Code:** Built with clean structure, straightforward variable names, and helpful comments in both English and Hindi.
- **In-Browser React Execution:** Runs React 18 and Babel directly in the browser via CDN without requiring Node.js build tools.
- **Responsive & Modern UI:** Designed with card layouts, smooth transitions, and mobile-friendly styling.

   ```bash

   ```
