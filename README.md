# Full Stack Development (FSD) Lab Assignments

A single-page interactive web application containing 6 Topic-wise Lab Assignments covering JavaScript Functions, DOM Manipulation, Form Validation, and Core React Concepts.

🌐 **Live Demo:** [https://gxdlrishabh07.github.io/FSD-Assignment/](https://gxdlrishabh07.github.io/FSD-Assignment/)

---

## 📚 Table of Contents

| # | Assignment Title | Topics Covered | Key Technologies |
|---|------------------|----------------|------------------|
| 1 | **Assignment 1: JavaScript Calculator** | Functions, Switch Statement, Arithmetic Operations | Vanilla JavaScript, HTML5, CSS3 |
| 2 | **Assignment 2: DOM-based To-Do List** | Dynamic DOM Elements, Event Handling, Class Toggle | JavaScript DOM (`createElement`, `appendChild`, `remove`) |
| 3 | **Assignment 3: Form Validation** | Real-time Validation, Regular Expressions (RegEx), Error Alerts | JavaScript Validation |
| 4 | **Assignment 4: React Profile Card** | Components, Reusability, Props Passing | React 18, JSX, Props |
| 5 | **Assignment 5: Controlled React Form** | Controlled Components, State Management, Real-time Live Preview | React `useState`, Event Handling |
| 6 | **Assignment 6: React Counter App** | State Hooks, Dynamic Color Classes, Increment/Decrement/Reset | React `useState`, Conditional Rendering |

---

## 🚀 Features
- **All-in-One Single Page Application:** Seamless navigation between all 6 assignments without page reloads.
- **Pure & Clean Beginner Code:** Written with clean structure, easy-to-understand variable names, and detailed comments.
- **In-Browser React Execution:** Runs React 18 and Babel directly in the browser via CDN without requiring complex build configurations.
- **Responsive & Modern UI:** Designed with clean card layouts, smooth transitions, and mobile-friendly styling.

## 💻 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/GxdlRishabh07/FSD-Assignment.git
   ```
2. Navigate into the folder:
   ```bash
   cd FSD-Assignment
   ```
3. Open `index.html` in any web browser (Google Chrome, Firefox, Safari, Edge):
   ```bash
   open index.html
   ```
